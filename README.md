# Phoenix 404

Public holding page for `fdroid.epassport-simulator.de`.

Only `index.html`, `404.html`, `fdroid.css` and `phoenix.png` are deployed. The two HTML files show the same link-free Phoenix 404 page. There are no application downloads, APKs, private project sources or imported repository history.

Publishing is manual through the **Publish only Phoenix 404** GitHub Actions workflow. All other Phoenix websites and downloads remain unpublished.

The owner explicitly authorized public visibility for **Zimphi/phonix_FDroid** on 2026-11-01, limited to this holding page and its public assets. This authorization does not apply to any other repository.
